# SimeGuardian

An opt-in wellbeing service for elderly Sime Darby Property township residents first, with broader scaling later. The hackathon prototype combines a native iPhone resident/family app built with Swift and SwiftUI in Xcode, a separate web MLOps dashboard, a synthetic data pipeline and trained anomaly detection across electricity, water, parking/car-plate movement, mall, gate and resident app signals. No new hardware is required.

Alerts go to family first, the resident after five unanswered minutes, then township after another five. An app check-in outcome, resident confirmation or sustained multi-signal AI recovery can close the incident. The dashboard traces data, training, model inference and app pop-up delivery. Withdrawal of monitoring and sharing completes within 23 hours.

Built for the Sime Darby Property University Hackathon 2026 (Township of Tomorrow).
