# Metropolis fonts

Metropolis is by Chris Simpson. These unmodified font files were downloaded on 21 October 2026 from the Sime Darby Property homepage assets documented in `docs/DESIGN.md`:

- `Metropolis-Regular.otf`: https://www.simedarbyproperty.com/home/fonts/Metropolis-Regular.otf
- `Metropolis-SemiBold.otf`: https://www.simedarbyproperty.com/home/fonts/Metropolis-SemiBold.otf

Both identify the upstream project as `https://github.com/chrismsimpson/Metropolis` in their font metadata. The upstream repository is archived at https://github.com/dw5/Metropolis; its Unlicense is included alongside these fonts. The files are served locally with `font-display: swap`, scoped to the township explorer.
